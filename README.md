# Spring Boot & Spring Ecosystem Learning Labs

Repository containing practical implementation labs, enterprise architecture experiments, and hands-on exercises developed during my study of Spring Boot 3/4, Spring Framework 6/7, and Hibernate.

## Repository Structure

* **Week-01-Spring-Boot-Overview**: Spring Boot bootstrapping, autoconfiguration internals, Spring Boot DevTools reload cycles, production telemetry via Actuator, and environment property bindings.
* **Week-02-Spring-Core-IoC-DI**: Spring Core Inversion of Control (IoC), dependency injection styles, component scanning, qualifiers, bean scopes, lifecycle hooks, and Java configuration.
* **Week-03-Hibernate-JPA-CRUD**: Relational data persistence with Jakarta Persistence and Hibernate, DAO layer architecture, transaction management, and JPQL queries.
* **Week-04-REST-API-Architecture**: RESTful web services with Spring MVC, DTO mapping, multi-tier architecture, and global exception handling pipelines.
* **Week-05-Spring-Data-JPA-REST**: Dynamic repository proxy generation with Spring Data JPA, derived query methods, hypermedia APIs via Spring Data REST, and OpenAPI/Swagger documentation.
* **Week-06-Spring-Security-REST**: Stateless REST security filter chains, HTTP Basic authentication, BCrypt password hashing, and role-based access control (RBAC).
* **Week-07-Spring-MVC-Validation**: Server-side rendering with Spring MVC and Thymeleaf, form model data binding, and Jakarta Bean Validation with custom constraint validators.
* **Week-08-FullStack-MVC-CRUD-Auth**: Full-stack MVC CRUD applications, Post-Redirect-Get (PRG) patterns, form-based authentication, CSRF protection, and role-based UI conditional rendering.
* **Week-09-Advanced-JPA-Mappings**: Complex relational topologies (1:1, 1:N unidirectional/bidirectional, M:N), cascading lifecycle operations, and query optimization eliminating N+1 select traps.
* **Week-10-AOP-Production-Observability**: Aspect-Oriented Programming (AOP), pointcut expressions, advice types, aspect precedence ordering, and cross-cutting audit and performance telemetry.

## Technical Environment

* Java 21 LTS
* Spring Boot 3.3+ / 4.x
* Spring Framework 6.x / 7.x
* Hibernate ORM 6.x
* Apache Maven
